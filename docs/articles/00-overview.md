# DeskBox 是什么？一款用桌面格子整理 Windows 文件的开源工具

DeskBox 是一款面向 Windows 10 和 Windows 11 的桌面整理工具。它在原有桌面上增加可以直接操作文件的格子，用来收纳散落的文件，或把电脑里已经存在的文件夹映射到桌面。文件仍然保存在普通的 Windows 文件夹中，也可以继续通过文件资源管理器访问。

如果你的桌面经常堆满截图、微信附件、下载文件和临时文档，DeskBox 想解决的就是这件很具体的事。

> 图片建议　先展示一个文件散落的桌面，再展示同一批文件进入几个格子后的状态。第一张图只出现文件格子，不要同时展示所有功能。

## Windows 桌面为什么很容易重新变乱

桌面是电脑上最方便的临时落点。截图会出现在这里，浏览器下载的文件会被拖到这里，聊天软件收到的文档也常常先放到这里。

问题通常发生在几天以后。文件名已经记不清，建立的临时文件夹越来越多，真正要用某份资料时，只记得它好像在桌面出现过。

传统的整理方法是把文件继续装进桌面文件夹。这当然有效，但文件夹一旦关闭，里面有什么就看不见了。另一种方法是依靠桌面分区，把图标摆进不同区域。这能改善视觉秩序，却未必能说明文件最终存放在哪里。

DeskBox 选择让格子与真实文件夹对应。桌面上看到的是格子，磁盘上保存的仍是普通文件和文件夹。你可以在格子里处理，也可以随时回到文件资源管理器中处理。

## 文件格子是什么

文件格子可以理解成一个一直放在桌面上的文件夹工作面。

你可以把文件从桌面、文件资源管理器或聊天软件拖进格子，也可以复制文件后选中格子并按 Ctrl+V。需要把文件发给别人时，再从格子中拖到微信、浏览器上传区域或其他支持 Windows 文件拖放的软件。

格子内可以进行多选、复制、剪切、粘贴、重命名、删除、排序和新建文件夹等常见操作。需要完整路径或更多系统操作时，也可以在文件资源管理器中打开对应位置。

这意味着用户不必学习一套孤立的文件格式。离开 DeskBox 后，文件仍然可以照常打开、备份、同步或移动。

## 收纳格子和文件夹映射有什么区别

第一次使用时，最需要弄明白的是这两个入口。

| 使用方式 | 文件放在哪里 | 适合什么情况 | 会不会搬动原文件夹 |
| --- | --- | --- | --- |
| 收纳格子 | 保存在 DeskBox 收纳路径下属于该格子的文件夹中 | 接收截图、下载、聊天附件和待处理文件 | 拖入或粘贴时会按设置复制或移动文件 |
| 文件夹映射 | 保持在你原来选择的文件夹中 | 把项目目录、素材库或常用文件夹放到桌面上 | 映射动作本身不会搬动文件夹 |

收纳格子适合接住新文件。你可以建立“待处理”“图片素材”或“本周交付”等格子，让刚来到电脑的内容先有明确位置。

文件夹映射适合已经整理好的资料。选择现有文件夹后，它会以格子的形式出现在桌面上。格子里的内容与原文件夹是同一批真实文件，因此重命名、删除和移动都会直接作用于原文件。

## 收纳格子里的文件实际保存在哪里

DeskBox 会让你确认一个收纳路径。以后创建的收纳格子会在这个路径下建立各自的文件夹，放进格子的文件也会实际保存在那里。

如果电脑有空间合适的非系统盘，首次设置时优先选择非系统盘会更稳妥。这样整理桌面后，文件不会继续占用 C 盘空间。只有一块磁盘也没有关系，之后仍可在设置中调整和迁移收纳位置。

文件夹映射不使用这条收纳路径。它只显示你选中的现有文件夹，文件仍留在原位置。

收纳路径决定文件真正落在哪里。建议在第一次放入大量文件前确认清楚，并把重要资料继续纳入自己的备份方案。

> 图片建议　用一张简单示意图说明“桌面文件进入收纳格子，再保存到 D 盘收纳路径”和“现有项目文件夹直接映射到格子”两条路径。

## DeskBox 会怎样整理已经堆在桌面上的文件

如果桌面已经积累了很多内容，可以先让 DeskBox 扫描并生成整理方案。执行前会列出准备处理的文件、识别的类型、目标格子和最终位置。用户确认以后才会移动文件。

文件夹、正在写入的文件、体积较大的文件以及状态无法安全判断的项目会谨慎留在原处。整理完成后仍应检查结果，重要项目也应保留日常备份。

这种方式适合处理已经形成的桌面杂物。以后继续出现的新文件，可以先拖进用途明确的格子。等使用习惯稳定后，再决定是否启用自动整理规则。

## 文件之外，还有哪些功能格子

文件整理是 DeskBox 的主要用途。需要时，你也可以把几种常用工具放进格子里。不需要的功能可以关掉，已经保存的内容和设置会保留，对应的界面和运行资源会释放。

| 功能格子 | 主要能力 |
| --- | --- |
| 待办 | 记录任务和截止时间，可以设置提醒、重复周期、颜色标记和附件，也能按状态筛选或批量处理。 |
| 随记 | 临时保存文字、链接、图片和文件。常用内容可以固定，记录较多时也能用不同纸张样式区分。 |
| 搜索 | 在桌面上查找文件、文件夹、应用、Windows 设置和 DeskBox 内容，支持筛选、多选和常用结果收藏。 |
| 天气 | 查看当前天气、逐小时变化和未来几天预报。格子大小变化时，内容会跟着调整。 |
| 音乐 | 读取 Windows 当前媒体会话，显示歌曲和封面，并控制播放、进度、播放模式与系统音量。 |

这些功能都围绕桌面上的短操作设计。待办不用先打开一套项目系统，暂停音乐也不必切回播放器。第一次使用仍建议先把文件格子弄明白，用到哪一种，再打开哪一种。

## DeskBox 和 Fences、iTop Easy Desktop 有什么区别

几款产品都在处理 Windows 桌面杂乱，做法差别很大。下面的内容依据各产品在 2026 年 8 月公开的介绍整理。功能、价格和授权方式以后仍可能变化。

### 文件怎样整理

| 选择 | 主要整理方式 | 显示已有文件夹 | 自动整理 | 文件操作 |
| --- | --- | --- | --- | --- |
| Windows 原生桌面 | 手动排列图标和建立文件夹 | 通过快捷方式进入文件夹 | 依靠用户手动整理 | 使用系统原有的拖放、复制、剪切和删除 |
| Stardock Fences | 用 Fence 区域管理桌面图标 | Folder Portals 可把文件夹内容显示在桌面 | 可按文件类型、名称、时间等条件建立规则 | 主要管理桌面图标，也可从 Folder Portal 访问真实文件夹 |
| iTop Easy Desktop | 自动分组，也可建立自定义桌面盒子 | Folder Portal 可访问电脑中的文件夹 | 支持自动归类桌面内容 | 围绕桌面盒子和文件夹入口处理本机文件 |
| DeskBox | 用收纳格子保存文件，用文件夹映射显示现有目录 | 可以直接映射已有文件夹 | 先预览整理方案，也可按规则处理后续文件 | 格子内支持拖放、多选、复制、剪切、粘贴、重命名和删除 |

### 平时怎样使用和显示

| 选择 | 显示与唤起 | 视觉表现 | 附加能力 |
| --- | --- | --- | --- |
| Windows 原生桌面 | Win+D 回到桌面，也可显示或隐藏全部桌面图标 | 保留 Windows 原有桌面样式 | 系统组件与桌面文件区彼此独立 |
| Stardock Fences | Peek 可把分区带到其他窗口上方，也支持快速隐藏、卷起和标签页 | 可调区域颜色、透明度和标签样式，并提供图标着色与渐隐效果 | Folder Portals、标签页和自动规则都围绕桌面分区展开 |
| iTop Easy Desktop | 双击桌面可隐藏内容，并能保存桌面布局 | 可调盒子颜色和透明度，另有静态与动态壁纸 | 提供私密盒子、时钟、番茄钟和天气 |
| DeskBox | 可用托盘、全局快捷键和胶囊模式唤起，按 Win+D 回到桌面时格子仍会保留 | 使用 WinUI 3 与 Mica、Acrylic 材质，可调透明度、边框、圆角和标题样式 | 提供待办、随记、搜索、天气、音乐、格子组和自动叠放 |

### 获取方式、代码和资源占用

| 选择 | 获取方式 | 源代码 | 公开的资源占用信息 |
| --- | --- | --- | --- |
| Windows 原生桌面 | 免费 | Windows 系统组件 | 不增加第三方桌面整理软件的常驻进程 |
| Stardock Fences | 收费 | 未公开 | 官网没有给出固定的内存或 CPU 占用数据 |
| iTop Easy Desktop | 免费与收费 | 未公开 | 官方称软件轻量，官网没有给出可与其他产品直接对照的测试数据 |
| DeskBox | 免费与收费 | GPLv3 开源 | 功能关闭后会释放对应运行资源，搜索空闲时可卸载本地索引，实际占用仍会随格子、文件和预览数量变化 |

资源占用很难只靠一个数字说清。文件数量、缩略图、搜索索引、动态壁纸和正在显示的格子都会改变结果。几款产品目前也没有在同一台电脑、同一套桌面内容下公开测试，因此这里不把它们简单标成高、中、低。

Fences 的桌面分区、自动规则和外观设置更成熟。iTop Easy Desktop 把自动分组、壁纸和桌面小工具放在一起。DeskBox 更关注真实文件夹、收纳路径、完整文件操作和 Windows 原生观感，也公开源代码。

DeskBox 的 GitHub 版本免费，Microsoft Store 版本收费，两者功能相同。商店版主要提供更方便的安装与更新，也是支持项目继续维护的一种方式。

如果桌面文件很少，Windows 原生桌面已经够用。需要长期可见的分类区域、现有文件夹入口或自动规则时，再根据自己最在意的部分挑选工具会更实际。

## DeskBox 适合哪些人

下面几类使用习惯通常更容易感受到文件格子的价值。

1. 桌面经常出现截图、附件、安装包和临时文档
2. 同时处理多个项目，希望每个项目都有一个看得见的文件入口
3. 经常从微信或浏览器收发文件，不想反复打开多层目录
4. 已经有整理好的项目文件夹，只想把它们映射到桌面
5. 在意文件真实路径，希望退出软件后仍能直接访问全部资料
6. 偏好本地工具、开源软件和接近 Windows 的界面

如果你已经严格使用固定目录，桌面几乎没有文件，也不需要把常用文件夹放在眼前，那么继续使用文件资源管理器可能已经足够。

## DeskBox 会替换 Windows 桌面或文件资源管理器吗

不会。Windows 仍然负责桌面和文件资源管理器，DeskBox 只是增加格子与相关操作入口。

收纳格子和文件夹映射背后都是普通文件夹。关闭 DeskBox 后，可以继续从磁盘路径访问文件。卸载应用时，收纳路径中的用户文件也应单独确认和保留，不要把软件卸载当成文件备份。

## DeskBox 会上传文件吗

DeskBox 不要求注册账号，格子配置、待办、随记、搜索历史和收纳文件主要保存在本机。天气、更新检查、安装依赖，以及用户主动导入网络链接等操作会在需要时联网。

如果收纳路径位于 OneDrive 或其他同步目录中，文件会遵循对应同步服务的规则。这个同步来自所选目录，DeskBox 本身不会把本地文件自动上传到自有云端。

## 第一次使用建议怎么开始

安装完成后，先完成四个动作就够了。

1. 确认收纳路径，电脑有非系统盘时优先放到非系统盘
2. 找到屏幕右侧已经创建的第一个文件格子
3. 拖入一个不重要的测试文件，再尝试从格子拖回桌面
4. 需要更多格子时，右键任务栏托盘中的 DeskBox 图标并选择新建格子

如果已经有常用项目目录，再创建一个文件夹映射。先用一两个格子完成日常文件收纳，熟悉以后再尝试桌面整理、自动叠放、格子组、搜索或其他功能。

## 常见问题

### DeskBox 支持哪些 Windows 电脑

DeskBox 支持 Windows 10 和 Windows 11，并提供 x64 与 ARM64 安装包。Windows 11 能呈现更完整的界面效果。

### DeskBox 是免费软件吗

GitHub 版本可以免费下载，源代码采用 GPLv3 许可证公开。Microsoft Store 版本功能相同，购买商店版可以直接支持项目继续维护。

### DeskBox 能作为 Fences 的替代工具吗

可以把它列入选择范围，但两者的设计重点不同。Fences 在桌面图标分区、自动化规则和外观定制方面更成熟。DeskBox 更强调真实文件夹、文件收纳路径、文件夹映射、本地使用和开源。如果这些正是你在意的部分，DeskBox 会更接近你的需求。

### 删除格子会不会删除文件

关闭文件格子时，应根据弹窗选择保留收纳文件夹、把文件移回桌面，或将文件夹移入回收站。涉及真实文件的选项会明确说明去向。重要文件仍建议先备份，再执行批量移动或删除。

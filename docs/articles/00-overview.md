# DeskBox：重新整理 Windows 桌面，把文件格子和实用小组件放在手边

Windows 桌面原本是一个很特别的地方。

它既是文件临时落脚的地方，也是你每天打开电脑后最先看到的工作区域；既可以放项目文件，也可以放快捷方式、截图和下载内容；它离正在使用的窗口最近，却很少真正被设计成一个好用的工作空间。

于是很多人的 Windows 桌面最后会变成这样：

- 文件越积越多，图标挤在一起。
- 微信、浏览器、下载目录和项目文件互相穿插。
- 临时文件不敢删，又不知道应该放到哪里。
- 想看天气、听歌、记待办，只能再打开几个独立应用。
- Windows 有信息小组件，却很难把“正在处理的文件”和“今天要做的事”放到同一个顺手的位置。

桌面不是没有功能，而是缺少一套真正围绕桌面来设计的整理方式。

DeskBox 做的事情，可以先用三个关键词概括：

> **整理桌面、建立格子、补齐 Windows 桌面小组件。**

它不是把待办、笔记、天气和音乐简单装进同一个软件里。它首先想解决的是：如何让 Windows 桌面重新成为一个清楚、顺手、能长期使用的工作入口。

## DeskBox 首先不是“效率工具合集”

如果只看功能列表，DeskBox 似乎包含文件管理、待办、随记、搜索、天气和音乐，容易让人以为它是一个“什么都有一点”的效率工具。

但这不是它真正的产品逻辑。

DeskBox 的核心不是把所有内容集中到一个应用窗口里，而是把这些能力放回它们最应该出现的地方：**Windows 桌面**。

- 文件应该在桌面上有清楚的落点。
- 正在处理的项目应该有一个稳定的入口。
- 今天要做的事应该在抬眼可见的位置。
- 临时复制的内容应该能在桌面附近找回。
- 天气和音乐应该是轻量状态，而不是需要反复打开的完整应用。
- 桌面不使用时应该能够安静收起，但需要时又能快速出现。

所以，DeskBox 的所有功能最后都服务于同一个目标：

> **让桌面更有秩序、更容易进入工作状态，也更适合长时间放在 Windows 上使用。**

## Windows 桌面真正缺的是什么？

Windows 本身已经有资源管理器、桌面图标、任务栏、系统托盘和小组件入口，但它们解决的是不同问题：

- 资源管理器适合完整管理文件，但不一定适合把正在使用的目录一直放在眼前。
- 桌面图标可以放文件，却很快会失去层次和分类。
- 任务栏适合切换正在运行的应用，不适合承载项目文件和临时内容。
- 系统托盘适合放常驻程序，但不适合展示一个项目当前的上下文。
- Windows 小组件适合查看信息，但通常不负责接收文件、连接项目目录或承接工作中的临时内容。

DeskBox 补上的，就是这中间的一层：一个属于桌面、又比普通图标更有组织能力的工作层。

它可以让你在桌面上放置真正的文件格子，也可以把待办、随记、天气、音乐和搜索做成同样轻量的格子。它们可以展开、收起、移动、组合，必要时从其他应用页面上直接唤起。

## DeskBox 的第一主线：把混乱的桌面整理出结构

### 不是把文件藏起来，而是给文件建立可理解的去处

桌面整理最容易走向两个极端：

一是所有文件都散在桌面上，靠记忆寻找；二是刚收到文件就强迫自己立刻分类，最后因为分类成本太高而放弃。

DeskBox 更适合一种中间方式：先给文件一个清楚的临时去处，再根据实际工作流逐步整理。

比如可以先建立：

- **待处理**：刚从微信、浏览器、邮件或下载目录来的文件。
- **当前项目**：正在进行的项目目录。
- **输出与交付**：已经制作完成、等待发送或归档的文件。
- **常用资料**：模板、参考资料和高频使用的目录。

这样做的重点不是让每个文件一开始就进入最终目录，而是先让桌面恢复可读性：你知道新文件在哪里，也知道接下来应该处理哪一类内容。

### 一键整理：先看计划，再整理桌面

当桌面已经堆满文件时，DeskBox 可以扫描桌面，并按照文档、图片、媒体、安装包、压缩文件、快捷方式和其他类型生成整理计划。

在真正移动之前，用户可以看到：

- 哪些文件会被整理。
- 每一类文件会进入哪个格子。
- 目标格子的实际收纳位置。
- 哪些文件会保留在桌面，以及具体原因。
- 本次整理会涉及多少项目。

确认之后，DeskBox 才执行真实的文件移动，并提供执行进度、结果和最近一次整理的撤销入口。

这和“点击一下，系统自己把桌面搬空”完全不同。桌面整理应该让用户知道发生什么，再决定是否执行。

> [动图占位：从混乱桌面开始扫描，展示分类卡片、目标格子、不会移动的项目，确认后执行整理并显示完成结果]

### 自动整理：让桌面从此不再持续变乱

一键整理解决的是“已经乱了怎么办”，自动整理解决的是“以后新来的文件怎么办”。

自动整理默认关闭，开启后会以当前桌面状态建立基线，只处理之后新出现并且已经稳定写入的文件。下载增长、解压、聊天接收和导出文件都可能经历写入过程，DeskBox 会等待文件稳定后再判断是否整理。

它会跳过文件夹、临时文件、云文件占位符、正在写入的文件、权限不足的项目和过大的慢速文件。没有明确规则时，文件会留在桌面，不会擅自创建新的格子。

因此，自动整理更像一个有边界的桌面收件员，而不是一个不问原因的文件搬运器。

详细阅读：[桌面一键整理与自动整理](02-desktop-organization.md)。

## DeskBox 的第二主线：用桌面格子代替杂乱图标

桌面格子是 DeskBox 最核心的产品形态。

普通桌面图标只能表示“这里有一个文件”；文件格子则可以表示“这里是一组有用途的内容”，并提供更完整的操作、布局和交互。

### 收纳格子：给新文件一个临时收件箱

收纳格子背后是真实的普通文件夹。你可以把微信附件、浏览器下载、截图和项目导出文件拖进去，DeskBox 按设置执行复制或移动。

收纳格子适合处理“文件刚到，但还没有最终归档位置”的阶段。它既比桌面图标更有结构，又不会要求你提前设计一套复杂目录。

### 映射文件夹：把已有项目目录放到桌面

如果文件已经存在于某个项目目录、代码仓库、设计素材库或同步文件夹中，可以直接使用映射文件夹。

映射不会复制文件，也不会改变原目录位置。它只是给这个真实目录增加一个桌面工作入口。你在格子中打开、重命名、移动或删除文件时，操作仍然作用于原目录。

这让 DeskBox 更像桌面上的“项目入口层”，而不是另一个封闭的文件系统。

### 格子比普通文件夹多了什么？

文件格子可以提供：

- 图标和列表两种查看方式。
- 名称、类型、大小、修改时间和手动排序。
- 复制、剪切、粘贴、复制路径、重命名和回收站删除。
- 从资源管理器、微信、浏览器拖入。
- 从格子直接拖到微信、浏览器上传区域或资源管理器。
- 文件预览、路径提示、快捷方式启动和多选批量操作。
- 位置、尺寸、标题栏、图标和显示密度设置。
- 自动叠放和胶囊收起。

但它依然遵守一个重要边界：文件本来在哪里，就仍然是普通文件；DeskBox 只提供一个更好的桌面工作面。

详细阅读：[文件格子与桌面收纳](01-file-widgets.md)。

## DeskBox 的第三主线：补齐 Windows 缺少的桌面小组件

Windows 有小组件，但很多时候你需要的并不是一个独立的信息资讯面板，而是几个真正贴近当前工作的轻量组件：

- 在桌面边缘看今天还有哪些任务。
- 在项目文件旁边放一段临时说明。
- 复制过的文字稍后还能找回。
- 不打开播放器就能暂停和切歌。
- 不切换应用就能看天气和预报。
- 需要时从桌面快速搜索文件、应用和工作内容。

DeskBox 的功能格子就是为这类需求设计的。

### 待办格子：桌面上真正能推进事情的小组件

待办格子不试图替代团队项目管理工具，它更适合放置“今天就要处理”的个人任务和文件相关任务。

它支持截止日期、Windows 通知提醒、稍后提醒、每日/工作日/每周/月度重复、重要状态、颜色标记、筛选标签、多附件和批量操作。

它还可以把文件直接挂到任务上。比如“发送合同”这条任务旁边，可以直接看到合同文件，而不是只在任务里写一句“合同在项目文件夹里”。

### 随记格子：比剪贴板稳定，比正式笔记更轻

随记用于接住临时内容：一段客户回复、一个网页链接、几张参考图、会议中的决定、一个需要稍后复制的文字模板，或一份不想立刻归档的文件。

它提供“记录、固定、最近”三个视图：

- 记录已经决定保留的内容。
- 固定常用地址、回复、链接和模板。
- 最近保存本机最近复制的文字、链接和可选图片。

随记支持多图片、多附件、纸张样式、图片文字复制、详情编辑和搜索。它不要求你现在就建立完整知识库，只负责把有价值的临时信息接住。

### 天气格子：把天气放回桌面的自然位置

天气格子提供当前位置、城市搜索、实时天气、逐小时和多日预报，还可以显示降水、湿度、风力、日出日落和紫外线。

它支持标准和高级皮肤、摄氏/华氏度、不同风速单位，以及随格子尺寸变化的日视图和周视图。需要联网时使用 MSN 天气或 Open-Meteo，定位失败也可以手动选择城市。

### 音乐格子：一个不会打断工作的播放器控制面板

音乐格子通过 Windows 媒体会话控制当前播放器，提供播放、暂停、上一首、下一首、播放进度、播放模式和音量控制，并显示曲名、歌手和专辑封面。

它可以使用封面模式、控制模式、唱片布局或自动布局，也可以根据专辑封面生成氛围背景。它不是音乐库，而是一个贴在桌面上的当前媒体控制面板。

### 搜索格子：把桌面内容和 DeskBox 内容一起找出来

搜索可以覆盖文件、文件夹、应用、设置、待办和随记。它支持 Windows 系统索引和可选的本地扩展索引，也可以显示最近搜索、推荐和收藏。

搜索结果不止能打开：还可以复制路径、打开所在位置、用 QuickLook 预览、保存到随记，或直接附加到待办。

这些小组件共同补上的，是 Windows 桌面中“看得见、够轻量、又能直接参与工作”的一层。

详细阅读：[待办格子](03-todo-widget.md)、[随记格子](04-quick-capture.md)、[桌面搜索](06-desktop-search.md)、[天气格子](07-weather-widget.md)和[音乐格子](08-music-widget.md)。

## DeskBox 的第四层：让桌面格子更好用，而不是更复杂

整理好桌面、建立好格子之后，DeskBox 还提供了一组增强体验的能力。它们不是产品起点，但会决定你愿不愿意长期使用。

### 全局唤醒：人在微信页面，也能使用桌面格子

默认按 `F7`，或使用自定义全局快捷键，可以从微信、浏览器、编辑器和其他页面上唤起格子。你不需要先回到桌面、打开资源管理器、翻到某个目录，再把文件拖进微信。

唤起后可以直接从格子拖出文件，也可以把资源管理器、微信和浏览器中的内容拖入格子、待办或随记。这个动作依赖 Windows 原生拖放，因此不建议把 DeskBox 设置为管理员运行，避免权限级别不同造成跨应用拖放失败。

详细阅读：[全局唤醒与跨应用拖放](05-global-wake-and-drag-drop.md)。

### 胶囊模式：信息常驻，但不把屏幕占满

格子可以保持展开，也可以收起为胶囊。胶囊能够显示文件数量、今日待办、随记数量、天气状态或音乐摘要；需要操作时，用点击、悬停、拖入或 F7 重新展开。

待办和随记还能在收起状态隐藏正文，适合共享屏幕和会议演示。胶囊可以独立摆放，也可以组合成一个整体移动的右侧信息栏。

胶囊隐私只是展示控制，并不是文件加密或应用数据加密。

详细阅读：[胶囊模式](09-capsule-mode.md)。

### 格子组：在同一个工作面里切换多个格子

一个项目可能同时需要文件、待办和随记，但不一定需要三个窗口同时展开。格子组可以把多个格子合并到同一个表面，通过标题栏成员选择器、滚轮或键盘切换当前成员。

格子组不会合并真实文件夹，也不会删除或合并成员数据。它解决的是桌面空间和上下文切换问题。

详细阅读：[格子组](10-widget-groups.md)。

### 自动叠放和 QuickLook：让文件格子保持整洁

自动叠放可以按文件类型、时间或自定义扩展名把文件收成视觉上的叠放组，减少同一格子里的图标噪音。它不会创建真实子文件夹，也不会移动文件。

安装并运行 QuickLook 后，在格子或搜索结果中选中文件按 `Space`，可以先预览再决定是否打开。

详细阅读：[文件自动叠放与 QuickLook](11-file-stacks-and-quicklook.md)。

### 外观与交互：让它真的属于你的桌面

DeskBox 支持跟随系统、浅色和深色主题，以及云母、云母 Alt、轻薄亚克力、标准亚克力和纯色材质。你可以设置透明度、材质浓度、边框、圆角、显示密度、标题栏、标题图标、悬停按钮、动画、位置和尺寸锁定。

设置窗口还提供搜索，可以直接查找“透明度”“附件”“快捷键”“动画”等选项，不需要逐页翻设置。

详细阅读：[外观与交互](12-appearance-and-interaction.md)。

## 一个更好的 DeskBox 使用方式：先整理桌面，再补组件

DeskBox 不建议一上来把所有格子全部打开。更舒服的路径通常是从桌面本身开始。

### 第一步：先建立一个“待处理”格子

它不是最终归档区，而是桌面收件箱。先把从微信、浏览器、邮件和下载目录来的东西集中起来，避免桌面继续增长。

### 第二步：再映射一个当前项目目录

选择一个你每天都会打开的真实目录，让它成为桌面上的项目入口。不要为了使用 DeskBox 重新设计整个文件系统。

### 第三步：只选择最需要的两个小组件

如果你经常忘事，启用待办；如果你经常复制临时内容，启用随记；如果你每天找文件，启用搜索；如果你希望桌面边缘有状态，再加入天气或音乐。

### 第四步：最后使用胶囊、叠放和自动整理

当桌面已经有稳定的结构，再使用胶囊减少占用、使用自动叠放降低文件噪音、使用自动整理处理之后新来的文件。

这套顺序的重点是：**先解决桌面混乱，再解决桌面密度，最后才是桌面美化。**

## 三种适合长期使用的桌面布局

### 方案一：干净桌面

适合大多数用户：


- 左侧放待处理文件格子。
- 右侧放待办和随记。
- 天气和音乐收起为胶囊。
- 使用 F7 统一唤起和隐藏。

### 方案二：项目工作台

适合设计、开发、运营和内容创作：

- 映射当前项目目录。
- 创建项目输出格子。
- 放置项目待办和项目随记。
- 用格子组或胶囊组合减少窗口数量。
- 对素材格子启用自动叠放。

### 方案三：桌面信息栏

适合希望信息一直在视线边缘的人：

- 天气、音乐、待办组成右侧胶囊栏。
- 文件格子独立停靠在另一侧。
- 待办和随记使用摘要或隐私显示。
- 工作时保持主应用区域干净。

## DeskBox 的产品边界

DeskBox 是桌面整理工具，不是所有软件的替代品。

- 文件格子不会替代复杂的资源管理器操作。
- 待办不会替代团队项目管理和多人协作。
- 随记不会替代完整知识库。
- 音乐格子不会建立音乐库。
- 天气格子需要联网获取天气数据。
- QuickLook 需要用户安装并运行 QuickLook。
- 胶囊隐私不等于加密。

它的价值在于把每天反复发生、又不值得打开大型应用的桌面动作变短。

## 本地优先，但不是所有功能都离线

DeskBox 不要求注册账号，也不依赖云同步。格子配置、位置、待办、随记、搜索历史和 DeskBox 托管附件默认保存在本机。

天气、更新检查、缺少运行时依赖时的安装下载，以及浏览器远程链接导入等功能会按具体场景联网。映射到 OneDrive、网络盘或其他同步目录的文件，也会继续受到这些外部服务状态影响。

应用数据备份可以保护设置、格子配置、待办、随记和 DeskBox 托管附件，但不等于整个映射目录的文件备份。重要文件仍应使用独立的备份方案。

详细阅读：[备份、恢复与维护](13-backup-recovery-and-maintenance.md)。

## 谁适合使用 DeskBox？

DeskBox 更适合这些人：

- 觉得 Windows 桌面越来越乱，想先建立秩序再谈效率的人。
- 经常处理微信、浏览器、邮件附件和下载文件的人。
- 希望把常用文件夹直接放在桌面、但不想改变原目录的人。
- 想要比 Windows 默认小组件更贴近工作内容的桌面组件的人。
- 同时需要文件、任务和临时记录，但不想打开一整套复杂系统的人。
- 使用共享屏幕、双屏或高分辨率桌面，希望控制信息密度的人。

如果你只需要完整的团队协作、复杂项目依赖、正式知识管理或整机备份，那么 DeskBox 不会替代那些专业工具。它更像是工作开始之前、工作进行之中以及工作交付之前，始终贴在 Windows 桌面上的那一层。

## 常见问题

### DeskBox 最主要的功能是什么？

最主要的功能是整理 Windows 桌面，并用桌面格子建立文件和文件夹的工作入口。待办、随记、搜索、天气和音乐等功能，是在这个桌面基础上补齐的轻量小组件。

### DeskBox 和 Windows 自带小组件有什么区别？

Windows 自带小组件更偏信息查看；DeskBox 的小组件直接和桌面工作流相连，可以接收文件、连接真实文件夹、关联待办和随记，并通过格子、胶囊和全局快捷键参与日常操作。

### DeskBox 会替换 Windows 桌面吗？

不会。它是在现有桌面上增加一层独立的格子窗口，资源管理器仍然是文件系统的主要入口。

### 文件格子会不会改变我的原文件？

收纳格子的拖入行为可以设置为复制或移动；映射格子直接反映真实目录；桌面整理在预览和确认后移动符合条件的文件；自动叠放只改变展示，不移动文件。

### 自动整理会不会一开启就搬走整个桌面？

不会。自动整理开启时会建立当前桌面基线，只处理之后出现且已经稳定写入的新文件。已经存在的文件需要通过一键整理单独预览和确认。

### 为什么不直接使用普通文件夹？

普通文件夹依然是底层文件结构，DeskBox 在它之上增加了桌面位置、格子布局、跨应用拖放、胶囊、叠放、全局唤醒和小组件协作能力。

### 是否要把所有功能都打开？

不需要。建议先从一个待处理格子、一个项目目录和最需要的一个小组件开始，等桌面工作流稳定后再增加自动整理、胶囊、格子组和其他组件。

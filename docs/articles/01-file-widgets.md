# DeskBox 文件格子与桌面收纳：收纳文件夹和映射文件夹怎么选？

很多人的桌面问题不是文件太多，而是每个文件都处在“稍后再处理”的中间状态：微信收到的附件先放桌面，浏览器下载的资料先放桌面，项目导出的文件也先放桌面。等到桌面变成一片图标，才开始重新分类。

DeskBox 的文件格子给这些文件一个更容易看见、也更容易操作的入口。它不是虚拟网盘，格子背后仍然是普通 Windows 文件夹。

## 一句话理解文件格子

文件格子是桌面上的文件夹工作面：你可以在这里查看、打开、排序、复制、移动、重命名和拖放文件，但文件最终仍然存在于真实路径中。

## 收纳格子和映射文件夹有什么区别？

### 收纳格子：给新文件一个临时归宿

创建收纳格子时，DeskBox 会在默认收纳根目录下建立真实文件夹。它适合承接刚收到、还没有决定最终归档位置的文件。

常见命名方式：

- 待处理
- 本周交付
- 微信附件
- 截图
- 当前素材
- 安装包

收纳格子的拖入行为可以设置为“复制”或“移动”。第一次使用建议保留复制，确认工作流稳定后再考虑移动。

### 映射文件夹：把已有目录放到桌面入口

映射文件夹不会复制目录，也不会创建另一份文件。它只是把已有目录展示成一个桌面格子。

适合映射的目录包括：

- 当前项目目录
- 代码仓库
- 设计素材库
- 常用模板
- OneDrive 中的工作目录
- 正在维护的客户资料目录

在映射格子里重命名、移动或删除文件，真实目录也会发生变化。因此，映射格子不是只读预览。

| 你的需求 | 更适合的选择 |
| --- | --- |
| 文件刚到电脑，暂时不知道归档到哪里 | 收纳格子 |
| 已有目录结构，不想搬动文件 | 映射文件夹 |
| 想保留来源文件，同时在 DeskBox 中留一份 | 收纳格子 + 复制 |
| 想让拖入后的来源位置不再保留文件 | 收纳格子 + 移动 |
| 想快速查看项目目录 | 映射文件夹 |

## 创建第一个文件格子

1. 右键系统托盘中的 DeskBox 图标。
2. 选择创建文件格子，输入用途型名称，例如“待处理”。
3. 将一张测试图片拖入格子。
4. 右键标题，确认可以在资源管理器中打开对应目录。
5. 再通过“映射文件夹”连接一个已有项目目录。

建议先用两个格子体验：一个负责接收新内容，一个负责连接正在工作的项目。

## 从微信、浏览器和资源管理器拖入

文件格子支持 Windows 原生拖放。常见场景包括：

- 从资源管理器拖入文件或文件夹。
- 从微信聊天窗口拖入聊天附件。
- 从浏览器拖入下载后的文件。
- 从浏览器拖入可以下载的远程图片或文件链接。

来自聊天软件和浏览器的内容有时只在拖放瞬间可用。对于重要附件，建议使用“复制到 DeskBox”或先保存到本地，再拖入收纳格子。

拖入时注意格子提示：不同目标可能显示复制、移动或不允许操作。跨磁盘、权限差异和目标目录权限也会影响 Windows 最终行为。

## 从格子拖到微信或其他软件

从文件格子拖出不是“导出”，因为文件本来就是普通文件。目标软件决定接收方式：

- 拖到微信，通常会进入文件发送流程。
- 拖到资源管理器，按 Windows 文件操作语义复制或移动。
- 拖到支持文件上传的浏览器页面，可以继续上传。
- 拖到其他支持 Shell 拖放的软件，使用其自己的接收规则。

如果格子已经收起成胶囊，先用鼠标悬停、点击或全局快捷键唤起，再开始拖动文件。

## 格子内的常用操作

文件格子支持：

- 双击打开文件或文件夹。
- Ctrl 加点击选择多个项目。
- Shift 加点击选择连续范围。
- 在空白处拖动使用选择框。
- 复制、剪切、粘贴和复制路径。
- 重命名、删除到回收站、打开所在位置。
- 将文件移动或复制到其他文件夹。
- 锁定格子位置或尺寸。

批量删除、批量移动和重命名都会影响真实文件。执行前先确认选择数量和目标位置。

## 图标、列表、排序和显示细节

图标视图适合图片、设计素材和需要视觉识别的文件；列表视图适合办公文档、安装包和需要同时查看名称、类型、大小、日期的目录。

你还可以调整：

- 文件名可用宽度。
- 名称、大小、类型和修改日期等列表信息。
- 图片预览是否只显示图标。
- 鼠标移入文件时是否显示完整路径提示。
- 按名称、类型、大小、修改日期或手动顺序排列。

这些设置只改变展示，不会修改文件内容。

## 删除格子和删除文件不是一回事

删除收纳格子时，DeskBox 会提示如何处理背后的收纳文件夹。删除映射格子只会移除 DeskBox 中的入口，不应直接删除映射目录中的原文件。

如果一个收纳格子被删除后，真实收纳文件夹仍然保留，它可能会出现在“孤立收纳文件夹”维护列表中。你可以选择恢复为格子、打开目录、把内容移回桌面，或确认后移到回收站。

## 适合长期使用的四格布局

一个实用起点是：

1. **待处理**：所有暂时没有最终归属的新文件。
2. **当前项目**：映射当前正在做的项目目录。
3. **常用资料**：映射模板、证件扫描或高频参考资料。
4. **输出与交付**：保存已经生成、等待发送或归档的成果。

使用一两周后再拆分。分类太细会让“应该放哪里”变成新的负担。

## 重要边界

- 收纳格子设置为移动时，来源位置的文件会消失。
- 映射格子中的删除会作用于真实目录。
- 文件格子备份主要保护配置和关系，不自动备份所有外部映射目录。
- 重要项目仍应使用版本控制、文件历史记录、云盘或其他独立备份。
- 不建议在 DeskBox 运行时手动编辑内部应用数据 JSON。

## 常见问题

### 文件格子会改变原文件位置吗？

创建收纳格子不会改变已有文件；拖入时是否复制或移动由设置决定。映射文件夹不改变目录位置，但格子内的文件操作会直接作用于该目录。

### 可以把文件从 DeskBox 直接拖到微信吗？

可以。只要微信当前窗口接受 Windows 文件拖放，就可以从展开的格子拖出文件。

### 收纳格子和文件夹有什么不同？

收纳格子是 DeskBox 的桌面入口，底层仍是普通文件夹。它额外提供了布局、胶囊、自动叠放、快捷唤起和跨应用拖放能力。

### 自动叠放会把文件移动到子文件夹吗？

不会。自动叠放只改变格子内的视觉分组，真实目录结构保持不变。

# DeskBox 全局唤醒与跨应用拖放：在微信、浏览器页面上快速拿文件

很多人已经把文件整理好了，但真正发送文件时，还是要先最小化当前软件、回到桌面、打开资源管理器、找到目录，再把文件拖进微信。

DeskBox 的全局唤醒解决的是这个“最后一公里”：你可以在其他页面上唤起格子，直接从格子中把文件拖到目标软件。

## 一句话理解全局唤醒

全局唤醒让 DeskBox 的格子不必常驻在最前面：需要时通过托盘或全局快捷键显示、隐藏或临时提升格子，完成拖放后再回到桌面层级。

> [动图占位：微信聊天窗口保持打开，按 F7 唤起 DeskBox，从文件格子拖出一个文件到微信发送区域]

## 默认 F7 怎么用？

默认全局快捷键是 `F7`。在其他应用处于前台时：

1. 按一次 `F7`，显示或唤起 DeskBox 格子。
2. 选择目标格子，找到文件或先展开胶囊。
3. 完成查看、拖放或编辑。
4. 再次按 `F7`，隐藏全部格子，或按当前托盘行为结束临时唤起。

如果 F7 与游戏、输入法、IDE、截图工具或厂商功能键冲突，可以进入 `设置 > 快捷与交互 > 全局快捷键` 重新录制。录制时按 Esc 可以取消。

## 托盘是另一条稳定入口

右键系统托盘中的 DeskBox 图标，可以：

- 显示全部组件。
- 隐藏全部组件。
- 显示随记。
- 创建文件格子。
- 打开设置。
- 打开收纳目录。
- 整理桌面。
- 设置开机启动。
- 退出 DeskBox。

左键托盘图标通常用于临时唤起或提升现有格子。它适合不记快捷键，或正在排查快捷键冲突的情况。

## 从格子拖到微信、浏览器和资源管理器

文件格子使用 Windows 原生拖放，因此不需要先导出或生成临时压缩包：

1. 通过 F7 或托盘唤起 DeskBox。
2. 将鼠标移到目标格子；如果格子是胶囊，悬停或点击展开。
3. 选中文件并按住鼠标左键拖动。
4. 将文件拖到微信聊天窗口、浏览器上传区域、资源管理器目录或其他支持文件拖放的软件。
5. 松开鼠标，观察目标软件的接收状态。

拖出文件时，目标软件决定是上传、复制还是移动。DeskBox 不会把“拖到微信”伪装成一种特殊导出格式。

> [图片占位：用三条箭头分别展示“格子 → 微信”“格子 → 浏览器上传框”“格子 → 资源管理器”]

## 也可以反向拖入

从资源管理器、微信或浏览器把内容拖进文件格子时：

- 收纳格子默认通常按复制处理，来源保留。
- 可以在文件格子设置中改成移动。
- 映射文件夹遵循目标真实目录的 Windows 操作语义。
- 浏览器远程图片或文件链接需要在确认导入后下载。
- 来自聊天软件的虚拟文件更适合选择复制保存。

拖入待办或随记时，文件会成为任务或记录附件；拖入胶囊时，DeskBox 会在需要时临时展开并提示“添加到待办”或“添加到随记”。

## 为什么建议不要“以管理员身份运行”？

Windows 可能阻止不同权限级别的窗口之间进行拖放。如果 DeskBox 以管理员权限运行，而微信、资源管理器或浏览器以普通权限运行，跨应用拖放可能失败。

除非有明确的系统管理需求，不要在快捷方式兼容性设置中勾选“以管理员身份运行此程序”。

## 胶囊如何配合全局唤醒？

胶囊不是一个只能看的状态。需要操作时可以：

- 鼠标悬停标题区域，等待自动展开。
- 点击胶囊切换展开状态。
- 按 F7 统一唤起所有格子。
- 将文件拖到胶囊附近，让目标格子临时展开。

完成拖放后，格子可以再次收起，减少长期占用的桌面面积。

## 快捷键冲突怎么处理？

优先避开：

- 游戏和显卡覆盖层。
- 输入法切换键。
- IDE 调试或运行快捷键。
- 截图、录屏和会议软件。
- 笔记本厂商的功能键。

如果新的组合键设置失败，换一个组合并完全退出、重新启动 DeskBox。搜索格子还可以配置独立的搜索快捷键，不必和“显示/隐藏全部格子”使用同一组按键。

## 一个高频文件发送流程

适合运营、客服、销售和经常给客户发资料的人：

1. 把常用资料映射成文件格子。
2. 工作时让格子保持胶囊状态。
3. 在微信聊天窗口按 F7。
4. 展开“交付资料”格子，拖出文件发送。
5. 发送完成后再次按 F7，恢复干净的工作面。

这个流程减少的是窗口切换和路径回忆，不改变微信或 Windows 的文件接收方式。

## 常见问题

### F7 按下没有反应怎么办？

检查 DeskBox 是否仍在运行、快捷键是否启用、组合是否被其他程序占用，以及当前应用是否拦截了功能键。可以先通过托盘确认 DeskBox 正常，再重新录制快捷键。

### 隐藏全部格子后还能唤回吗？

可以通过 F7 或托盘显示全部格子。若某个格子位置发生变化，先打开设置或参考故障排查中的屏幕外窗口处理方法。

### 可以把随记里的图片直接拖到微信吗？

随记中的图片和文件附件可以使用其复制或拖出操作；如果目标软件只接受文件，优先拖出附件文件，而不是复制一段组合文本。

### 为什么从微信拖文件到 DeskBox 失败？

检查 DeskBox 是否以管理员权限运行、目标格子是否有写入权限、来源是否是虚拟文件，以及收纳格子的复制/移动行为是否符合当前目标。

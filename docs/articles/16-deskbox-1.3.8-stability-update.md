# 从 DeskBox 1.3.5 到 1.3.8，让每天都会用到的动作更顺一点

从 1.3.5 升级到 1.3.8，最容易感觉到的变化，是格子的显示、收起和切换更顺了。

按下快捷键，格子会跟着同一组动画来到眼前。短时间连续按几次，DeskBox 也会按顺序完成，不再让几次显示和隐藏互相打断。以前偶尔会遇到窗口没有回来、停在屏幕外或暂时失去响应，现在这些情况都经过了重新处理。

Win+D 的行为也改了。按下 Win+D 回到桌面时，DeskBox 格子会继续留在桌面上，不会像普通窗口一样一起消失。需要处理文件时，仍然可以用快捷键把格子临时带到当前应用上方。这个变化很简单，却更接近桌面格子应该有的感觉。

## 动画更连贯，后台也少做一点重复工作

这一轮主要调整了格子组切换、胶囊展开和整体显示隐藏。

以前胶囊展开时，窗口尺寸、文件列表和图标可能同时开始变化，偶尔会有一下停顿。现在会先把窗口动画走稳，再继续较重的内容加载。快速切换格子组时，刚打开的内容也会短暂保留，避免关掉以后马上再加载一遍。

用户看到的结果很直接。胶囊展开更自然，格子组来回切换更连贯，文件较多时也少一些突然的空白和闪动。DeskBox 同时减少了几类重复加载，长期放在桌面上时，后台少做一些无用功。

我没有给这些变化写一个固定的性能百分比。文件数量、缩略图和电脑配置都会影响结果。流畅性最终还是要看鼠标移过去的那一下，画面有没有跟上。

## 文件操作终于更像熟悉的文件夹

1.3.8 补齐了几处每天都会碰到的操作。

从桌面复制文件后，可以选中格子直接按 Ctrl+V。格子内多选几个文件，再复制或剪切到外部文件管理器，也会完整带上全部选择。文件移动完成以后，原来的半透明剪切样式会及时清理，不会错误地跑到其他文件上。

新建文件夹会自动滚动到眼前并进入命名，文件可以直接拖进格子里的文件夹。手动排好的顺序在重新启动后仍会保留。独立文件格子和格子组现在也使用相同的菜单与操作方式，加入格子组以后不用重新适应。

右键菜单重新排过顺序，刷新和粘贴放在上面，危险操作留在底部。关闭格子时，文件是保留、移回桌面，还是进入回收站，弹窗会把去向写清楚。

## 打开、删除和卸载都有明确结果

用户主动删除全部文件格子后，下次启动不会再自动补回。开机启动时，DeskBox 会安静留在托盘；用户主动打开时，应用会正常回应。升级沿用原来的安装位置，卸载时可以选择保留应用数据，也可以彻底清理。收纳路径中的用户文件始终保留。

新用户第一次打开 DeskBox 时，第一个文件格子会放在屏幕右侧。引导先说明文件实际保存在哪里，再解释文件夹映射，也会告诉用户怎样从托盘新建格子。应用和安装器现在还增加了六种语言，共提供十一种界面语言。

当前 1273 项自动测试已经全部通过。测试不能代替每一台电脑上的实际使用，但能减少修好的问题再次出现。

我希望 1.3.8 给人的感受很朴素。按 Win+D，格子还在。按快捷键，它会顺利出现。复制三个文件，过去的也是三个。DeskBox 长期放在桌面上，应该尽量少让用户停下来确认它有没有做对。

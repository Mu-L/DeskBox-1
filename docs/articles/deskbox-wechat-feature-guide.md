# Windows 桌面总会重新变乱，DeskBox 用格子把它理顺

桌面大概是 Windows 里最容易够到的地方。

刚截完的图片放在这里，从微信收到的文档先拖到这里，浏览器下载的文件也经常顺手留在这里。每一次都很合理。用上几天，图标慢慢铺满屏幕，文件名开始记不清，真正需要某份资料时，又要打开文件资源管理器一层层翻。

桌面整理工具要解决的，正是这些每天都在重复的小动作。桌面要保持清楚，常用文件也得容易拿到。只把图标藏起来，过一会儿还得重新找。

DeskBox 在原有 Windows 桌面上增加了一组格子。文件可以直接放进格子，也可以把电脑里已经存在的文件夹映射到桌面。格子内保留拖放、复制、剪切、粘贴和多选等熟悉操作，文件本身仍是普通的 Windows 文件。

## DeskBox 的主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 收纳格子 | 接收桌面、文件资源管理器、微信和浏览器中的文件，并保存到明确的收纳路径 |
| 文件夹映射 | 把已有项目目录、素材库或常用文件夹直接显示在桌面上 |
| 桌面整理 | 扫描已经堆在桌面上的文件，先展示移动方案，确认后再处理 |
| 自动叠放与格子组 | 在不改变真实目录结构的情况下整理显示，并把相关格子放到一起 |
| 功能格子 | 在桌面查看待办、随记、搜索、天气和音乐 |
| 胶囊模式 | 把格子收成紧凑入口，需要时再展开，也可以组合排列 |

这些功能可以分开使用。第一次打开时，先用一个文件格子就够了。桌面整理、功能格子和外观设置都可以等熟悉以后再开。

## 文件格子有两种用法

DeskBox 里的文件格子分为收纳格子和文件夹映射。两者在桌面上的操作很接近，文件去向并不相同。

### 收纳格子接住新文件

收纳格子适合处理刚来到电脑、还会继续使用的内容。你可以建立“待处理”“图片素材”或“本周交付”等格子，再把截图、聊天附件和导出文件拖进去。

每个收纳格子背后都有一个真实文件夹。DeskBox 首次运行时会让用户确认收纳路径，以后创建的收纳格子会在这个路径下建立各自的目录。电脑有空间合适的非系统盘时，可以优先选择 D 盘或其他固定磁盘。当前桌面位于 C 盘时，移入格子的文件也会真正转到所选的非系统盘。

拖入时可以根据设置复制或移动。复制会保留来源文件，移动会把文件转入格子对应的文件夹。文件要发给别人时，再从格子中拖到微信、浏览器上传区域或其他支持 Windows 文件拖放的软件。

> 配图占位　收纳流程动图。从桌面和微信各拖入一个文件，格子内出现对应项目，随后在文件资源管理器中打开真实收纳路径。

### 文件夹映射让旧目录不用搬家

已经整理好的项目目录没有必要重新移动。文件夹映射会把选中的现有文件夹显示成桌面格子，文件仍留在原来的位置。

比如项目资料一直放在 `D:\项目`，素材保存在独立硬盘，或者常用文件处在 OneDrive 目录中，都可以直接创建映射。格子显示的内容与原文件夹是同一批文件，在格子里重命名、移动或删除，原目录也会发生相应变化。

收纳格子负责接收新内容，文件夹映射负责把旧目录带到眼前。新建入口都在任务栏托盘菜单中。右键 DeskBox 图标，可以继续创建格子或选择文件夹映射。

## 格子里保留了常用文件操作

文件整理软件用久以后，真正影响体验的往往是一些很普通的动作。能不能一次选中多个文件，复制以后能不能完整粘贴到资源管理器，剪切完成后状态会不会及时清除，这些动作每天都会碰到。

DeskBox 的文件格子支持图标和列表布局，也能调整排序方式、图标大小与显示密度。格子内可以多选文件，继续使用 Ctrl+C、Ctrl+X 和 Ctrl+V，也可以重命名、删除、新建文件夹或在文件资源管理器中显示当前位置。

需要快速查看内容时，如果电脑已经运行 QuickLook，可以选中文件后按空格预览。这个功能沿用 QuickLook 的文件格式支持范围，DeskBox 不会额外复制一份文件。

> 配图占位　操作动图。依次展示框选多个文件、复制到外部文件资源管理器、从外部粘贴回格子，以及按空格调用 QuickLook。

## 桌面已经乱了，可以先看整理方案

有些桌面已经积累了几百个文件，靠手动拖动很难一次收拾完。DeskBox 可以扫描桌面内容，再生成准备执行的整理方案。

方案中会列出识别到的文件类型、接收它们的格子和最终路径。某一类不想移动，可以在确认前留下来或更换目标。用户确认以后，DeskBox 才会开始处理真实文件。

正在下载、解压或写入的文件需要多等一会儿。DeskBox 会观察文件是否已经稳定，状态拿不准时就留在原处。文件夹、体积较大的项目和权限不足的内容也会采用更谨慎的处理方式。

桌面整理处理已有文件，自动整理负责以后新出现的内容。自动整理默认关闭，开启后可以按文件类型等规则把新文件送到指定格子。刚开始使用时，先为一种常见文件建立规则，观察一段时间，再决定是否增加更多规则会更稳妥。

## 自动叠放整理显示，格子组节省位置

同一个格子里的图片、文档和压缩包多起来以后，可以打开自动叠放。它会按照规则在格子内部形成不同分组，方便收起和展开。

自动叠放只调整显示。真实文件夹里不会凭空多出一层分类目录，关闭叠放后，文件仍在原来的位置。

几个文件格子经常一起使用时，还可以把它们组成格子组。组内成员共享桌面位置和尺寸，通过标题入口、鼠标滚轮或 Ctrl+Tab 切换。项目文件夹不会因此合并，拆出某个成员时也不需要重新搬文件。

## 胶囊模式让桌面留出更多空间

格子一直展开，内容看得清楚，占用的桌面面积也会增加。胶囊模式可以把格子收成一个更紧凑的入口，只保留图标、标题、数量或简短摘要。

胶囊支持点击展开，也可以在鼠标悬停时自动展开。文件拖向收起的格子时，它能临时打开，方便确认目标。多个胶囊还可以组合成一条可以整体移动和排序的胶囊栏。

DeskBox 也保留了桌面和普通窗口的区别。按下 Win+D 回到桌面时，格子会继续留在桌面上。正在其他应用中工作，需要临时访问文件时，可以通过托盘或自定义的全局快捷键把格子带到眼前，操作结束后再让它回到桌面层。

## 文件之外，还有五种功能格子

文件整理是 DeskBox 的主要用途。用户需要时，也可以把几种频繁查看的内容放到桌面边缘。每种功能都能单独关闭，关闭后保存的数据和设置仍会保留，对应界面与运行资源会释放。

### 待办格子

待办适合记录今天要处理的任务，也能为事项增加截止时间、提醒、重复周期、颜色标记和附件。任务多起来以后，可以按状态筛选或批量处理。

### 随记格子

随记可以保存临时文字、链接、图片和文件。常用记录能够固定，多张图片和多个附件可以放在同一条内容中，纸张样式用来区分不同用途。

### 搜索格子

搜索可以查找文件、文件夹、应用、Windows 设置和 DeskBox 内容。结果会分阶段出现，也支持筛选、多选、历史和收藏。可选的本地文件索引在空闲后能够卸载，关闭搜索功能时会释放完整搜索运行资源。

### 天气格子

天气格子显示当前天气、逐小时变化和未来几天预报。标准皮肤会跟随系统明暗模式，高级皮肤会根据天气变化调整画面，格子尺寸改变后，日视图和周视图也会重新排布。

### 音乐格子

音乐格子读取 Windows 当前媒体会话，可以显示歌曲、歌手和封面，并控制播放、进度、播放模式与系统音量。它提供封面、控制、唱片和紧凑布局，也能让背景颜色跟随专辑封面变化。

## 视觉可以融入 Windows 桌面

DeskBox 使用 WinUI 3 和 Windows App SDK 构建。Windows 11 下可以选择 Mica 云母或 Acrylic 亚克力材质，并调整透明度、边框、圆角、标题栏、图标和文字大小。

有人喜欢让格子明显一些，文件分类一眼就能看到。也有人只想留下很淡的边界，让壁纸继续成为桌面主体。这些外观可以按格子和使用习惯调整。Windows 10 会根据系统能力降低部分材质和动画效果，文件操作与格子功能仍可继续使用。

> 配图占位　外观对照图。使用同一组格子展示 Mica、Acrylic 和紧凑胶囊三种状态，壁纸与窗口位置保持一致。

## 文件与数据主要留在本机

DeskBox 不要求注册账号。格子配置、待办、随记、搜索历史、窗口布局和收纳文件主要保存在电脑上。关闭应用后，收纳格子和文件夹映射背后的普通文件夹仍能通过文件资源管理器访问。

天气、更新检查、缺少的安装依赖，以及用户主动导入的网络链接会在需要时联网。如果收纳位置本身处于 OneDrive 等同步目录中，文件会按照对应服务的规则同步。

资源占用会随文件数量、缩略图、索引和正在显示的格子变化。DeskBox 会在功能关闭后释放对应运行资源，搜索空闲时可以卸载本地索引，隐藏或空闲的动态格子也会减少不必要的动画工作。

## 第一次使用可以从一个格子开始

安装完成后，DeskBox 会在屏幕右侧创建第一个文件格子。先确认收纳路径，再拖入一个不重要的测试文件，随后试着复制、粘贴和拖回桌面。

这几个动作顺手以后，再右键任务栏托盘中的 DeskBox 图标创建新格子。电脑里已经有整理好的项目目录，可以直接新建文件夹映射。自动整理、格子组和功能格子都可以晚一点再开。

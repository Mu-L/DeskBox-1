# 给桌面文件一个看得见、找得到的位置

桌面乱起来，往往没有一个明确的开始。

可能是一张刚截完的图，一份从微信收到的文档，或者一个下午还要继续处理的表格。每次都只多一个文件，看起来不值得专门整理。几天以后，它们已经盖住了壁纸，文件名也慢慢失去意义。

我们把文件放在桌面，是因为这里离正在做的事最近。DeskBox 想做的，是保留这份方便，同时给文件一个更清楚的去处。

## 用格子接住每天来到电脑上的文件

DeskBox 会在 Windows 桌面上放置可以直接操作文件的格子。

你可以准备一个“待处理”格子，接收刚下载或刚收到的内容。再准备一个“本周交付”格子，放已经整理好、随时可能要发送的文件。

文件可以从桌面、文件资源管理器或聊天软件拖进来，也可以复制后在格子中按 Ctrl+V。需要发送时，再把多个文件一起拖到微信或浏览器上传区域。

在格子里，打开、排序、多选、复制、剪切、粘贴、重命名和删除这些熟悉的操作都还在。

## 格子背后仍是普通文件夹

DeskBox 不会把文件变成只有自己才能读取的数据。

每个收纳格子背后都有一个真实的 Windows 文件夹。你在桌面上看到格子，文件实际保存在磁盘路径中。退出 DeskBox 后，仍然可以通过文件资源管理器访问、备份和移动这些文件。

第一次使用时，应用会请你确认收纳路径。以后所有收纳格子都会在这个路径下建立各自的文件夹。

电脑有空间合适的 D 盘或其他非系统盘时，建议优先把收纳路径放在那里。这样把桌面文件收入格子后，文件也会真正离开 C 盘。只有一块磁盘也能正常使用，之后仍可调整位置。

## 已经整理好的文件不用重新搬家

有些文件本来就有合适的位置。

项目资料在 D 盘，照片在素材库，代码在固定仓库。这些目录不需要为了桌面整理再移动一次。

这时可以使用文件夹映射。选中现有文件夹后，它会作为一个格子显示在桌面上。文件仍留在原路径，格子中的重命名、移动和删除也会直接作用于原文件。

收纳格子接住新文件，文件夹映射把已有文件夹带到桌面。

> 配图建议　左右两条路径。左边展示桌面文件进入收纳格子并保存到非系统盘，右边展示现有项目目录直接映射到桌面。

## 整理桌面之前先看看文件会去哪里

桌面已经堆满时，可以让 DeskBox 扫描并给出整理方案。

方案会列出准备处理的文件、识别类型、目标格子和最终路径。点击确认以前不会移动文件。文件夹、正在写入的文件、体积较大的文件和状态不明确的项目会谨慎留在原处。

文件整理关系到真实路径。看清去向，再执行移动，会比一个只有“立即整理”的按钮更让人放心。

## 和其他桌面整理工具有什么不同

Windows 上已经有 Fences、iTop Easy Desktop 等桌面整理工具。它们解决的问题相近，做法各有侧重。

| 产品 | 主要特点 | 已有文件夹入口 | 获取方式 | 更适合的需求 |
| --- | --- | --- | --- | --- |
| Stardock Fences | 成熟的桌面分区、自动规则、Peek、标签页和丰富外观设置 | Folder Portals | 商业软件，提供试用和多种授权方式 | 看重桌面图标分区、自动化和视觉定制 |
| iTop Easy Desktop | 自动分组、桌面盒子、壁纸、私密盒子和多种桌面工具 | Folder Portal | 免费版加 Pro 版 | 希望快速整理并获得一套桌面美化与工具组合 |
| DeskBox | 真实文件夹支持的收纳格子、明确的收纳路径和文件夹映射 | 文件夹映射 | GitHub 免费开源，商店提供功能相同的支持版 | 看重文件真实位置、本地使用、开源和 Windows 原生观感 |

Fences 在桌面分区领域积累时间更长，自动规则和外观定制也更成熟。iTop Easy Desktop 提供了更丰富的壁纸和附加工具。DeskBox 选择先把文件收纳这件事做好，让用户知道文件从哪里来、最后放到哪里，也能继续使用熟悉的文件资源管理器。

对只需要手动摆放少量图标的人，Windows 原生桌面已经够用。需要长期分类区域、已有文件夹入口或更完整文件操作时，再考虑安装桌面整理工具。

## 先学会四个动作就够了

第一次打开 DeskBox，可以先忽略大部分设置。

1. 确认文件收纳路径
2. 找到屏幕右侧的第一个文件格子
3. 拖入一个测试文件，再尝试复制、粘贴和拖出
4. 需要更多格子时，右键任务栏托盘中的 DeskBox 图标，选择新建格子或新建文件夹映射

用上几天以后，再去了解自动叠放、格子组、搜索、待办和随记。桌面不需要一次整理成某种标准样子，只要下一份文件出现时，你知道该把它放在哪里。

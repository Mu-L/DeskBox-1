# Windows 桌面总是越用越乱，有没有一种整理方法能长期坚持？

如果只是把桌面收拾干净，十分钟就够了。

难的是一周以后，它还会不会变回原样。

截图、微信附件、浏览器下载、临时导出的表格，每一个文件刚出现时都有用。我们把它放在桌面上，是因为桌面离手头的工作最近。等事情做完，这些文件失去了上下文，整理就变成一项很难开始的杂活。

所以很多人的桌面会在两种状态之间反复。某天忍不住全部塞进一个“桌面整理”文件夹，清爽几天，之后又重新堆满。

普通桌面给人的选择很少。文件可以散开放着，也可以装进一个关闭后看不见内容的文件夹。文件格子补上了第三个位置，它能把文件分开，又让内容一直看得见。

这也是 DeskBox 做文件格子的原因。

## 一个文件格子到底是什么

可以把它理解成铺在 Windows 桌面上的文件夹工作面。

比如你可以建立“待处理”“图片素材”和“本周交付”三个格子。微信刚收到的附件拖进待处理，截图放进图片素材，准备发送的文件放进本周交付。

要用时不用重新打开几层目录。文件就在格子里，可以打开、预览、重命名、复制、剪切、粘贴、删除，也可以多选后一起拖到其他软件。

这些文件没有被装进某种专用数据库。每个收纳格子背后都有一个普通 Windows 文件夹。退出 DeskBox 后，照样可以用文件资源管理器打开。

这点对文件工具很重要。界面可以改变，文件不能变得只有某个软件认识。

## 收纳格子并不是一个快捷方式

第一次使用时，最容易忽略的是收纳路径。

把文件拖入或粘贴到收纳格子后，DeskBox 会按照设置移动或复制文件。文件最终会进入你确认的收纳路径，并保存在对应格子的文件夹中。

电脑有 D 盘或其他空间合适的非系统盘时，我更建议把收纳路径放在那里。整理桌面以后，文件也就真正离开了 C 盘。只有 C 盘也能正常使用，之后再迁移即可。

如果你不希望搬动已有目录，可以使用文件夹映射。

## 文件夹映射适合已经整理好的人

假设你已经有一个 `D盘\项目\客户A` 文件夹，里面的层级和备份都安排好了。没有必要为了使用桌面格子再搬一次。

选择文件夹映射后，DeskBox 会把这个目录的内容显示在桌面格子中。文件仍留在原路径，格子相当于一个靠近桌面的操作入口。

要注意的是，显示在格子中的就是原文件。你在格子里重命名、移动或删除，原目录也会发生相同变化。

收纳格子负责接住新内容，文件夹映射负责把旧目录带到桌面。理解这句话，基本就理解了 DeskBox 的文件管理方式。

## 为什么不直接在桌面建几个文件夹

当然可以，而且对于文件很少的人，这可能就是最省事的办法。

文件格子的优势主要出现在日常操作里。内容一直可见，不用先打开文件夹，才能知道里面有哪些文件。格子还能显示、隐藏、调整大小和位置，需要工作时唤起，录屏或想看干净桌面时收起。常见文件操作也保留了下来，文件可以从桌面、资源管理器和聊天软件拖入，也能从格子拖到微信和浏览器上传区域。

如果这些动作在你每天的工作中出现很多次，少开几次目录就会变得很明显。

DeskBox 的 GitHub 版本免费开源，Microsoft Store 也有功能相同的支持版。Fences 提供试用、订阅和永久授权选项。iTop Easy Desktop 提供免费版和 Pro 版。价格和具体授权可能变化，下载前最好查看各自官网。

我会优先推荐给下面这些人。

## 第一次安装以后先做什么

别急着把所有功能都打开。

先确认收纳路径。电脑有非系统盘时，可以优先选择非系统盘。

然后找到屏幕右侧的第一个文件格子，拖进去一个不重要的测试文件。打开文件资源管理器，看一眼它实际保存的位置，再把它拖回桌面。

需要第二个格子时，在任务栏右下角找到 DeskBox 托盘图标，右键后选择新建格子。已有项目目录则选择新建文件夹映射。

先用一两个格子过几天。等你真的知道哪些文件总会出现，再考虑自动整理、格子组和其他功能。桌面工具只有进入日常动作，才有可能长期留下来。

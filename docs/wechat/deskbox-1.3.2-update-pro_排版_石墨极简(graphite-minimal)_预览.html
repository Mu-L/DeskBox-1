QUOTE

一个被收拾干净的桌面，最怕的从来不是乱，而是 找不到 。

1.3.0 把桌面收拾成了可以 收起的胶囊 ，1.3.1 又默默把图标、动画和启动项打磨了一遍。到了 1.3.2，我们想认真解决一个一直悬在桌面工具头顶的问题，当你把文件收进格子之后，怎么 最快地找到其中某一个 。

答案不是再开一个系统搜索窗口，而是 把搜索直接长在 DeskBox 里 。

01

SEARCH

桌面搜索：这次的主角

过去要在 DeskBox 里找一个文件，你得 点开对应的格子 ，在列表里翻。文件一多，这个过程就开始产生摩擦。1.3.2 新增的搜索系统，目标是让「找」比「翻」 快一个数量级 。

它的底层没有走最省事的那条路，即调用系统搜索框或现成索引，而是直接读取了 NTFS 的 USN 日志 （变更日志）。Windows 在 NTFS 分区上会持续记录每一个文件的创建、修改、删除和移动，相当于一份 始终在更新的磁盘账本 。搜索时直接消费这份账本，就不需要遍历目录树去逐个扫描，无论首次建索引还是后续增量更新，都比目录遍历快得多。

在此之上，搜索还接入了 Windows 索引 ，因此不仅能按文件名和路径匹配，也能搜到 文件正文里的内容 。比如你只记得某份文档里写过的一句话，输入关键词就能把对应文件定位出来。

交互层面，搜索是一个独立的弹窗，通过 全局快捷键唤起 ，输入即出结果。结果经过加权排序：名称命中、使用频率、最近访问时间都会影响排位，最常用的内容会自然靠前。它还提供搜索历史、按类型排序与筛选，以及一个可以用 纯键盘上下导航 的推荐应用面板。用完关掉弹窗，桌面依旧是那副干净的样子。

值得强调的一点是，这套搜索是 「为桌面而生」 的，而不是又一个全盘搜索器。它理解 DeskBox 所管理的那块空间，在你精心整理过的格子里找东西，比在系统搜索里 大海捞针 要精准。

— 搜索弹窗界面：左侧结果列表、右侧推荐应用面板，快捷键提示


02

LOCALIZATION

五种语言，和一次本地化架构重写

1.3.2 之前，DeskBox 只有中文和英文。这一版新增了 日语、德语和巴西葡萄牙语 ，每种语言都补齐了一千五百余条界面文案，现在一共支持 五门语言 。

比新增语言本身更关键的是底层改动。我们把沿用了许久的 .resw 资源方案，整体重写为一套基于 JSON 的本地化服务（ LocalizationService ）。新的结构让翻译贡献变得简单很多：译者面对的是清晰可读的 JSON，而不是散落在多处、难以对照的旧格式。对一款想要走向更多地区用户的桌面软件来说，这是一次 必要的地基升级 。


03

INSTALL

安装与更新：ARM64 终于来了

长久以来，DeskBox 只提供 x64 安装包，用 Surface、骁龙笔记本等 ARM64 设备的朋友只能旁观。1.3.2 补齐了 ARM64 安装包 ，并会在安装时正确识别 ARM64 平台的 .NET 10 与 Windows App Runtime， 自动补齐缺失的依赖 。

安装器本身也变聪明了。覆盖安装前，它会 可靠地关闭正在运行的 DeskBox 进程 ，再执行文件替换，告别过去偶尔弹出的「重试 / 忽略 / 取消」。安装器现在还会 根据系统区域预选语言 （中文、英文、日语、德语、巴西葡萄牙语），并把选择写入注册表，DeskBox 首次启动默认沿用，当然你在应用内手动切换依然优先。


04

FIXES

让日常更稳的那些修复

这一版也修掉了一些会 打断体验的问题 ，单独看都不大，但每一个都关系到「用着用着会不会 突然别扭 」。

最值得说的一个，关于 QuickLook 兼容 。1.3.0 我们加过一个很轻的 QuickLook 兼容：选中文件按空格即可预览，DeskBox 不去接管、不去扫描，有就用、没有就当不存在。但后来发现一个隐蔽的崩溃，当 QuickLook 建立了一个空连接时，DeskBox 的管道服务会直接挂掉，而且不容易复现。1.3.2 调整了可用性检查的逻辑，让它 不再去触碰那条命名管道 ，从根本上避开了这个崩溃。

「有就用，没有就当不存在——软件之间，不一定要互相接管。」

其余修复还包括：防止托盘动画过程中 丢失桌面壁纸 、修正托盘菜单高度、清理失效的 .lnk 快捷方式、修正天气代码映射。它们不会出现在更新日志的标题里，却是日常 顺不顺手的分界 。


05

ONBOARDING

引导与天气的小升级

第一次打开 DeskBox 的 引导流程被重做了 。旧版一上来就是成排的设置，容易让人发怵；新版拆成欢迎、功能、收纳、快捷键、完成五步，带入场动画，并且 完整覆盖五种语言 ，新用户能在几屏之内理解这个工具能做什么、该怎么开始。

天气部件也更好用了。 城市数据库从约 500 条扩展到 5000 多条 ，并加入了 面向中日韩的模糊搜索 ，小城市基本都能搜到。定位服务增加了超时处理与「上次已知位置」兜底，四种尺寸布局也做了细化。


06

DESIGN

视觉与交互的打磨

这一版在 「看着舒服、用着跟手」 上花的功夫，不比搜索少。

胶囊样式做了一次 全面的视觉优化 。收起状态下，图标、文字与间距的对齐被重新校准，整体 更紧凑、更一致 ；展开与收回的过渡也更顺。天气胶囊还移除了多余的标题图标，只保留天气 emoji，视觉更干净。

动画方面，1.3.2 引入了一套 硬件自适应的托盘动画系统 。它会根据你的 GPU 能力动态调整动画的精细程度：性能强的设备多给细节，弱一些的设备则自动收敛复杂度，保证流畅。配合批量动画驱动与同步调度，多个格子同时显示或隐藏时能够整齐联动，即便快速反复切换（比如连续按 F7 ），也不会再出现 画面撕裂或黑屏闪断 。

这些改进很难用一句话说清「好在哪」，但它们决定了你每天收起、展开格子几十次时， 手感和心情是否始终平稳 。


∞

EPILOGUE

写在最后

1.3.0 让桌面 安静下来 ，1.3.2 让桌面也变得「 找得到 」。它不是一个靠单个炸裂功能博眼球的版本，而是把过去几个月里，那些一直想补、该补的地方，一件件补上。

如果你已经在用旧版本， 直接覆盖安装即可 ，格子、设置、待办、随记和收纳目录都会保留。考虑到这是一次较大的版本，升级前仍然建议先到「设置 › 诊断与维护 › 备份与恢复」 导出一份备份 ，图个安心。
